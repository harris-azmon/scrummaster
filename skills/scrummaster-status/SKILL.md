# scrummaster-status

Displays the current progress of the project by parsing the Epics Index, fossil ACID ticket state, and individual story plans.

## Triggers
This skill is activated by the following phrases:

- "$scrummaster-status"

- "/scrummaster-status"

- "/scrummaster:status"

- "@scrummaster /status"


## Usage
To use this skill, simply type one of the triggers or ask the agent to "status".
